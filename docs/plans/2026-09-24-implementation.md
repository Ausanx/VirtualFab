# VirtualFab Implementation Plan

**Goal:** 交付本地可运行、可回放、可自定义且不夸大物理精度的首版工作台。
**Architecture:** 原生浏览器界面调用纯 JavaScript 工艺与结构识别函数；Three.js 只负责三维显示。
**Tech Stack:** Node 24、HTML/CSS、ES modules、Three.js、node:test。
**Spec:** `docs/plans/2026-09-24-virtualfab-design.md`。

用户已授权直接开始，采用 ponytail 要求的精简实现与当前会话执行，不引入额外审批、隔离仓库或多轮文档流程。当前目录尚无 Git 仓库，首次交付建立版本控制。

## Global Constraints

- 项目数据留在本机；无远程上传、云服务或运行时 CDN。
- 参数区分来源与条件，缺失不得当零；绝缘层不当作 PIN 的 i 层。
- 原始需求文档不覆盖；未实现的高精度模型明确列出。

## Review Focus

- 错误和过大的导入数据不得覆盖正在编辑的项目。
- 无开口、无显影和无胶时的沉积/lift-off 不可虚构成功。
- 被阻挡或未接触的材料不得推断直接 PN。
- 同一导体或不连通端子不得生成可工作的 FET。
- 缺失带边、光生参数或动态参数不得生成被称为预测的曲线。
