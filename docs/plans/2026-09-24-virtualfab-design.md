# VirtualFab 首版设计与验收

本文件记录对话确认后的设计，优先于初始 `virtualfab_engine_ui.md` 中尚未实现的远期架构。用户已同意直接实施，不再重复请求设计审批。

## 已确认目标

- 面向二维材料、薄膜、二端交叉阵列及三端晶体管；用户自由编排，也可从模板开始。
- 工艺包括衬底/划片、涂胶、烘烤、曝光、显影、沉积、刻蚀、去胶/lift-off、转移、退火；光刻过程不能从配方里省略。
- 材料覆盖 MoS₂、WS₂、WSe₂、石墨烯、InON、Te，常用金属、ITO、介质、衬底和具体牌号光刻胶（包括 NR9-3000PY）。材料可以自定义。
- 以材料角色、实际几何拓扑、器件功能分层判断。PN 与能带 Type-I/II/III 为独立标签；PIN 的 i 是本征或低掺杂半导体；介质不自动成为 i；MIM 不自动成为忆阻器。
- 每个参数保留条件、来源和 measured / derived / estimated / missing。缺失不是零；材料身份不永久确定载流子类型。
- 本地数据优先；不上传项目。TCAD 及完整三维物理求解属于后续扩展。

## 首版工程选择

用 Node 标准库启动 localhost 服务、原生 HTML/CSS/JavaScript 实现工作台，唯一运行时依赖 Three.js。数据保存在浏览器本地，可导入导出项目 JSON。原需求稿保留。

局部工艺区采用 XY 采样列与连续 Z 区间，每个材料区域记录产生步骤、掺杂状态、端子角色。衬底完整尺寸作为元数据；局部视窗的 μm 尺寸与 nm 膜厚分别标定。涂胶按顶表面覆盖，曝光记录目标开口和胶的正负性，显影移除开口内胶，定向沉积覆盖可见顶表面，lift-off 移除胶和其上沉积层。垂直刻蚀按时间与用户提供的材料速率逐层消耗；未提供速率的外露层保留并提示数据不足。

这是几何工艺近似：不声称解出了光化学、三维水平集、ALD 成核或真实侧壁覆盖率。横向网格限制需要显示。采用分层模型可保留超薄膜；后续需要掏空与通量的实验定量验证时再扩展求解器。

结构识别以实际接触边/三层路径为依据，端子和栅介质单独处理。候选结构可多标签共存。能带仅显示同一真空参考下的材料带边，明确其不是接触后自洽能带弯曲。简化 I–V 由用户明确给定的模型参数产生，不能伪装成材料名推算的真实性能；记忆和 DVS 需要动态模型证据。

## 界面方向

使用者在工艺前检查配方、在工艺后观察结构。核心视线落在器件局部、切片线及对应剖面。领域元素：晶圆、划片、胶层、开口、叠层、掩膜、带边、端子。颜色来自灰色硅片、蓝色介质、青色半导体、橙色电极和低饱和胶层；英文与数值使用 Arial，中文使用系统中文字体。深色精密工作台、细边框、4px 间距基准、12–16px 面板内距。工艺卡片显示步骤序号与实际完成状态，不使用营销面板或无意义仪表盘指标。

## 验收重点

1. 三类默认配方能回放每个光刻子步骤，并修改参数和重排。
2. lift-off 前后材料分布不同；刻蚀不穿过未消耗的阻挡层。
3. 不相邻材料不生成接触；p/介质/n 不识别 PIN；p/本征半导体/n 可识别 PIN。
4. 栅金属必须通过连续介质覆盖沟道，源漏必须连接沟道；模型给出证据和不足。
5. InON 缺失能带参数仍可工艺回放，不能画成零带隙；ITO 不归类普通金属；负胶按具体牌号记录。
6. JSON 往返保留参数、来源和步骤；错误导入不会破坏原项目。
7. 实测浏览器交互与视觉布局，核心逻辑用 Node 内置测试运行。
