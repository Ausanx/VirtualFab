# VirtualFab 物理闭环设计与验收

日期：2026-10-07。来源：用户调用 `grill-me` / `grilling` 后，对 Q1–Q12 的三轮答复均接受推荐方案。访谈中的路线选择已收敛，本文件记录需求与验收。随后用户授权开始实施；A–B 的首版实现见[工艺映射验证](../validation/device-equilibrium.md)，C–F 尚未完成。

本文件继承[首版设计](2026-09-24-virtualfab-design.md)与现有软件架构，补充后续物理闭环方向。当前代码基线为 `898e4a2`，工作分支为 `codex/local-dft`。

## 当前能力与新增工作的边界

当前 `src/engine.js` 使用 XY 采样列和连续 Z 区间；`contactGraph()` 的整数区域 ID 来自当前遍历与连通合并，不是跨重算的持久身份。当前 `p/n/i` 来自工艺卡，是结构候选标签。

当前 `src/equilibrium.js` / `solver/equilibrium.py` 求解独立的 300 K 一维体硅平衡算例，不读取工艺几何。已有正常 PN/PIN、短端部及粗网格负对照，详见[平衡验证](../validation/equilibrium-results.md)。

当前 DFT 使用显式原子结构、固定几何 PBE 和 Si/Mo/S 赝势；输入、计算证据及敏感度有验证，详见[DFT 方法](../validation/dft-method.md)与[结果](../validation/dft-results.md)。DFT 不自动供应样品掺杂、绝对带边或器件输运参数。

下一阶段先连接工艺区域与硅连续模型。全三维工艺物理、注入/扩散动力学、二维输运、原子级异质界面、SOC、杂化泛函、GW/BSE、光电和陷阱动态是后续独立模型，不作为首个硅闭环的验收要求。

## 1. 区域级掺杂与物理输入

### 输入语义

- 保留结构候选 `p/n/i/unknown`，与定量物理参数分开。
- 分别记录施主与受主浓度，单位 `cm⁻³`；说明数值代表名义杂质浓度、已激活浓度还是已电离浓度。实测自由载流子浓度不直接当作杂质浓度。
- 激活比例及电离模型分别记录；补偿由施主和受主共同表达。未知值为 `null`，零只在明确声明该类杂质缺席时使用。
- 参数具有来源、定位、适用条件和 `measured/derived/estimated/missing` 证据类型。论文测量值与论文模型假设分开记录。
- 首个基准限定均匀、完全电离、非简并 Boltzmann 模型。完全电离作为显式模型假设，可以用于公开理想算例；它不是用户样品的实测激活结论。
- 补偿和部分激活可以保存，但只有获得相应模型验证后才能用于求解。第一版求解限于现有无补偿 PN/PIN 范围，拒绝静默忽略额外输入。

### 空间绑定

物理参数绑定到明确的空间区域与产生步骤，不能只保存当前 `contactGraph()` 整数 ID。同一步骤形成的多个不连通部分必须能分开指定；同一连通 Si 体内的理想掺杂分区也必须能够表达。

工艺步骤、材料、网格、区域选择或求解路径改变时，重新核对物理绑定；区域消失、拆分、合并或出现歧义时，要求重新选择，旧结果标为历史。保留旧输入快照和结果，不能自动把它们关联到新区域。

当前工艺没有注入/扩散求解。理想基准允许用户在既有 Si 区域中指定分段掺杂，但界面与报告必须写明“给定掺杂分布”，不能称其为沉积、退火或注入步骤的预测结果。首个闭环的工艺部分验证材料与几何的构成，掺杂是独立的物理输入。

## 2. 工艺几何到一维硅模型的映射

### 用户流程

1. 回放到指定工艺状态，选择求解区域、两个端子和直线路径。
2. 提取沿路径的材料、连续区间、区域长度与掺杂分区，保留单位转换和来源。
3. 显示映射预览：工艺几何区间、物理计算区间及两者对应关系。
4. 补齐并确认温度、掺杂和边界条件，生成不可变求解快照。
5. 后台求解，分别显示求解状态、数值精度与验证状态。

### 首个版本的允许范围

- 300 K、零偏压、体硅同质 PN 或 PIN；理想欧姆端部、完全电离、Boltzmann 统计沿用已验证模型。
- 直线方向明确、横截面内输入一致、连续的硅求解域；只能产生 p–n 或 p–i–n 的连续区间。
- i 区是明确指定的本征硅；低掺杂区需使用真实浓度和受支持的模型，不能直接当作零净掺杂。介质与真空不属于 i 区。
- 求解域与物理接触范围分别显示。若端点是计算域截断边界而非实际电极，必须记录该理想边界，不能画成工艺生成的接触。

### 拒绝或失效条件

材料不受支持、路径存在间断或介质、端子短接、旁路或分支、显著横向不均匀、未解析的小尺寸特征、区域绑定歧义以及缺失必要输入，均不能生成有效定量模型。不能通过选择局部路径忽略整体短路或旁路。

一维适用性需要检查路径邻域和整体连通关系，不能只检查中心线上出现的材料序列。逐项列出检查依据；它是模型适用性检查，不是对真实三维器件的精度保证。

保留当前采样几何作为首阶段输入，不重写为三维网格引擎。截面变化、侧壁电流或边缘电场成为研究目标时，另立二维/三维模型，并重新验证几何与物理映射。

## 3. 输出与验收

### 首个硅闭环输出

- 平衡 `Ec(x)`、`Ev(x)`、`EF(x)`、电势、电子/空穴浓度和电场。
- 内建电势及明确操作定义的耗尽区宽度；耗尽近似与数值解分开。
- 原始节点/边场数据、模型参数、来源、边界条件、数值检查与输入快照。

耗尽区边界依赖所采用的定义。报告必须说明移动电荷判据或其他操作定义及其敏感性；不能把近似解析宽度冒充数值解唯一的精确边界。

暗态 J–V 在平衡闭环通过后扩展，需引入并核对漂移扩散、迁移率、复合参数、端子偏压和电流守恒。需要区分电流密度与电流；只有明确横截面积后才换算总电流。C–V、温度扫描、寿命和光生过程随后单独立项。

### 三层验证

1. 解析关系与连续 Poisson–Boltzmann 积分：检查单位、符号、费米能级平直、载流子关系、内建电势和正常算例的场分布。耗尽近似仅在其条件成立时比较。
2. 独立数值实现：使用独立离散/求解路线对同一方程、参数和边界条件比较。DEVSIM 自带示例和本应用共用 DEVSIM 时只算适配器回归，不算独立引擎验证。
3. 公开文献：逐项核对可获取的器件尺寸、材料状态、掺杂与测量条件。未知参数保持未知；使用同一数据拟合参数后的吻合属于标定，另留未用于拟合的数据或条件进行验证。

首个硅数值门槛沿用[现有基准](../validation/equilibrium-results.md)的模型检验条件：归一化离散 Poisson 残差小于 `10⁻⁶`；正常算例网格减半电势差不超过 `2 mV`、峰值场变化不超过 `2%`。这些是工程验收条件，不是学术领域统一标准或实验误差。独立实现比较统一单位、坐标、场采样位置和边界后报告差异。

保留短端部与粗网格负对照；分别添加缺参数、未知载流子类型、介质 i 区、端子短接、旁路、结构改动及绑定失效负对照。小离散残差、成功退出或漂亮曲线都不能替代这些检查。

## 4. 材料变体与文献档案

材料母类标识与材料变体标识分开。变体记录晶相、层数/膜厚、化学计量、衬底、制备方式与相关环境；不要求与所计算量无关的条件也成为必填项。掺杂仍是区域属性，可以引用变体默认假设，但不能被材料名永久决定。

参数版本保留来源和条件，不覆盖旧项目引用。对于同名且条件不一致的数据，可以并列保存，不能无依据求平均或自动替换。二维面密度 `cm⁻²` 与体密度 `cm⁻³` 不得直接混用；任何厚度换算都需明示模型依据。

后续首个二维对象选 MoS₂/WSe₂，先做结构、界面带阶与参考能级验证，再研究器件输运。参考 [Chiu 2015](https://doi.org/10.1038/ncomms8666) 和当前[文献验证](../validation/literature-calibration.md)。不同论文的衬底、制备和测量条件不可静默混成一套样品参数；相对带阶、真空参考、光学/准粒子/KS 带隙分别保存。

Te/InON 是后续目标。InON 需明确成分、结构状态和制备条件；缺少可定义的原子模型时，不能只凭材料名生成 DFT 输入。材料库允许缺失，并明确该缺失阻止哪些输出。

## 5. 验证状态与失败行为

“验证”按结果量、算例和条件分别记录，具有 `通过/未通过/未检查/不适用` 状态、方法、阈值、来源与时间：

- 算法核对：解析关系或独立实现比较。
- 数值精度：网格、截断能、k 网格等针对所输出量的检查。
- 文献基准：哪些参数和输出与公开资料比较。
- 实验标定：哪些数据用于参数确定，哪些数据用于独立验证。
- 工程估算：明确的假设和估算依据。

这些维度可以并存；一个项目不能因为某个量通过某项检查就统一盖“已验证”章。

| 情形 | 软件行为 |
| --- | --- |
| 必需参数缺失或模型不适用 | 阻止定量求解，显示缺失/不适用依据；允许继续工艺回放 |
| 求解未收敛、输出不完整或证据校验失败 | 保留诊断与证据，不显示为有效物理结果 |
| 求解收敛，精度检查未通过 | 可以查看和导出，图与文件保留“精度未通过”及具体失败项 |
| 精度通过，缺少实验依据 | 可以显示数值检查通过；实验标定状态仍为未检查 |
| 当前输入改变 | 旧结果保留为历史，禁止自动关联到新输入 |

导出采用数据文件加结构化元数据；CSV 保持机器可读，配套元数据保存输入哈希、单位、来源、模型和状态。图中包含结果状态与内部/绝对能量参考说明。缺失不是零。

## 6. 后台任务、资源与迁移

交互预览应在秒级反馈；正式计算显示等待、运行、取消和结束状态。首个闭环复用现有本地求解器与任务模式，默认最多一个活动计算，避免先引入集群或分布式调度。

运行前显示模型规模、线程配置、阶段时限和可用磁盘；只在有测试依据时给出 RAM/时间估计，并说明估计条件。资源不足时提供缩小模型或降低并发的操作。新增计算资源信息不能上传项目内容。

可迁移任务证据包包含输入快照、工艺映射、材料/模型参数版本、日志、结果、CSV/XML 等已有证据、清单和哈希，以及实际后端/赝势/适配器/数值库版本与哈希。默认不包含整个 WSL/QE 环境。

导入在临时隔离目录校验后再关联项目。拒绝目录穿越、绝对路径、损坏或截断文件、异常解压大小和不支持的版本；避免覆盖本机已有任务。证据校验与模型正确性分别说明。

历史结果可以在后端未安装或环境不一致时只读查看。重新计算需要兼容环境，否则创建新任务；原输入、原证据与环境漂移记录保留。波函数及 QE scratch 默认不归档，包内记录其缺失，因此任务包不保证任意后处理或 SCF 波函数续算。

## 实施顺序与完成条件

| 阶段 | 独立交付 | 完成条件 |
| --- | --- | --- |
| A | 区域物理参数与绑定 | 旧 v1 项目兼容；未知数据保留；拆分/合并/网格变化正确失效；保存重开保持来源与假设 |
| B | 一维映射与硅平衡闭环 | 用户预览端子/路径/区间；只有适用 PN/PIN 可提交；正负对照、旧结果隔离、桌面与导出通过 |
| C | 独立数值比较与公开基准 | 三层验证分别报告；适用条件、缺失项、误差与拟合/留出关系可追溯 |
| D | 任务证据包 | 无后端只读查看；兼容后端重算；中文路径、损坏、重复导入和环境不匹配检查通过 |
| E | 暗态硅 J–V | 参数完整、连续性与电流守恒、网格/偏压步长及独立基准检查通过 |
| F | MoS₂/WSe₂ 扩展 | 条件一致的材料/界面档案；结构与带阶先验收，再确定适用二维输运模型 |

先交付 A–B，C 与 D 分别验收；E–F 不与首个闭环捆绑。界面保持 Electron 本地应用及亮色 Vivado 式工作台风格。所有新增状态在原有工作流中呈现，避免把建模和验证变成额外的无关操作。

## 需要调查的事实，而非追加用户问卷

- 为硅基准选择可公开读取、参数和边界条件完整的资料；记录 DOI、正文/补充材料位置与不确定度。
- 选择许可证兼容、可本地运行的独立数值核对路线，验证它对现有 Poisson/Boltzmann 模型的适用性。
- 为区域绑定、截面一致性及路径检查制定具体数据结构与算法，通过拆分、合并、短路和粗网格用例验证。
- 测量当前硬件上真实算例的资源和运行时间，再制定资源提示。用户不需要提供可以从本机读取的信息。
- 后续二维与暗态模型先核实公开参数是否齐全；参数不足时缩小可输出量，并明确记录未覆盖的机制。

本轮没有剩余未回答的路线选择。上述事实调查由实施者完成；只有新证据迫使改变目标器件、适用物理、数据上传、费用或部署方式时，才重新讨论相关决定。
