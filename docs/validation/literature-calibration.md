# 文献标定与交叉验证方法

核对日期：2026-09-29。范围是当前 VirtualFab 工艺几何、接触拓扑与标量带阶模型，采用目的性选择的三篇代表论文，不是系统综述。来源包含期刊正文、原作者开放稿和补充材料；没有从综述插图或搜索摘要读取工艺数值。DOI、标题、期刊和年份已核对，参数定位保存在 `benchmarks/literature.mjs`，同时随样例写入 `benchmark.reference`。

## 运行

```powershell
npm test
npm run validate:literature
npm run validate:literature:strict
npm run test:literature:desktop
```

普通报告命令生成项目、CSV 和 JSON，退出码 0 表示报告生成成功。严格命令保留原始默认估算的外部挑战，当前预期返回 1；这表示通用默认库尚未获得独立实验标定。修复后的光学/未分类带隙不输出电子带阶，文献档案应用另列报告。工程测试、档案应用一致性与独立实验标定是三个结论，不能混写。

在桌面软件的“打开项目”中选择 `examples/literature/*.json`，逐步查看光刻、显影、蒸镀、剥离、薄膜和结构识别。`test:literature:desktop` 使用独立桌面配置模拟打开、逐步回放、切换能带视图并检查渲染；截图保存在 `artifacts/literature/`。默认运行开发桌面；追加 `-- --packaged` 可检查已有便携版。生成的文件只存于本机，运行时没有联网或上传数据。

## 三个基准

| 基准 | 原文输入与观察 | 当前验证内容 | 不能据此声称 |
| --- | --- | --- | --- |
| [Radisavljevic 2011](https://doi.org/10.1038/nnano.2010.279) | SiO₂ 270 nm；MoS₂ 0.65 nm；Au 50 nm；HfO₂ 30 nm；栅长 0.5 μm、宽 4 μm；EBL、蒸镀、剥离、ALD、再次 EBL | 层厚、两轮开口面积、金属保留、源漏独立、顶/底栅共用沟道 | 迁移率提升、开关比、阈值、栅漏电或 ALD 生长已复现 |
| [Lee 2014](https://doi.org/10.1038/nnano.2014.150) | WSe₂ 后叠 MoS₂，SiO₂ 280 nm；Pd/Au 20/30 nm 与 Al/Cr/Au 40/1/50 nm 独立接触；S2 模型重叠长 3 μm、面积约 8.8 μm²、端子间距 9 μm | 多金属层顺序/厚度、转移重叠、PN 与 HETERO 候选、采样面积误差 | 栅压可调整流、光伏、层间隧穿复合或完整带弯曲已复现 |
| [Chiu 2015](https://doi.org/10.1038/ncomms8666) | Type-II；VBO 0.83±0.07 eV、CBO 0.76±0.12 eV；STS 准粒子带隙 2.15/2.08±0.10 eV | 原始数值挑战；同参考 STS 带阶算术；有条件相对界面档案、膜厚及来源保护 | 档案应用等于独立预测，或测得带隙就获得绝对真空带边 |

Radisavljevic 的正文 Fig. 3 与 Methods、SI pp. 1-4 支持工艺顺序。Lee 的原作者开放稿 pp. 17-19 对应 SI S1-S2；实验电极厚度与 S2 数值模型的 200 nm 电极不是同一输入。Chiu 使用[已出版全文](https://hub.hku.hk/bitstream/10722/297973/1/content.pdf) pp. 3-4、Eq. (2)、Fig. 3；并核对[作者稿](https://arxiv.org/pdf/1406.5137)。

## 判定规则

1. **输入与输出独立核对。** 膜厚和层序来自原文；矩形面积、体积和刻蚀深度由解析式计算，不调用引擎的掩膜函数生成预期结果。厚度采用 10⁻⁸ nm 浮点容差，这是程序回归容差，不是实验测量精度。
2. **采样误差明确报告。** 对齐网格时检查准确面积；非对齐时使用矩形栅格误差界并扫描 32/40/64/80 列。0.5 μm 栅在 8 μm/16 列下消失，必须出现 `SUBGRID` 且不能识别双栅。该负对照防止“工艺跑完”被误当作“结构正确”。
3. **拓扑有负对照。** 禁用 EBL 后显影必须停止；源漏金属桥接不能识别 FET；异质层移开、载流子类型未知或加入介质不能继续认作直接 PN。介质夹层是 SIS，不能变成 PIN。
4. **刻蚀不移植无关速率。** 0.5 nm/s 是解析测试的指定输入，明确标 `estimated`；不把 Lee 的多层 ICP 刻蚀速率当成 HfO₂ 的标定速率。20 s 只减薄 10 nm、60 s 清除 30 nm；未刻掉的覆盖介质必须阻挡目标层。
5. **能带方向和参考固定。** `ΔEc = Ec(WSe2) - Ec(MoS2)`，`ΔEv = Ev(WSe2) - Ev(MoS2)`。文献档案的相对界面图与真空带边图分开，不计算 E(k)。随位置的平衡 E(x) 仅在新增独立 300 K 体硅 PN/PIN 模型求解，验证见 [平衡求解报告](equilibrium-results.md)。
6. **不把拟合当作验证。** 默认库与 Chiu 的外部测量作定量比较；误差超出原文区间即记为不通过。STS 相对带边的 0.72/0.79 eV 算例只验证参考平移不变性和方法一致性，不能冒充独立重复实验。由 VBO 和两带隙导出的 CBO 也不是新的独立验证数据。

## 保留的简化

样例使用矩形薄膜而不是原实验的多边形轮廓；衬底厚度、部分光刻胶牌号/厚度/时间、顶栅金属厚度等非原文输入均在项目 `benchmark.reference.assumptions` 中逐项记录。Radisavljevic 的 MMA/MAA + 2% PMMA 双层胶以单层几何掩膜代替，因此不验证下切和实际 lift-off 工艺窗口。Lee 的聚合物转移、约 0.7 nm vdW 间距和石墨烯边缘接触未被物理求解。膜厚单位和退火记录可以保留，但不计算成核、应力、污染、缺陷和接触电阻变化。

Chiu 项目将 STS 带隙写作 `measured` / `quasiparticle`，亲和能保留 `missing`。项目显式选择 Chiu 界面档案并记录条件确认；相对带阶只在实际单层接触时输出，关闭条件确认或改变膜厚会停止应用。真空参考图仍显示带边缺失，载流子类型仍未知，不自动认作 PN。它不是一个经过独立实验验证的器件。

## 当前结论与补齐顺序

当前可以验证理想工艺回放、层厚/层序、解析图形以及几何拓扑。默认能带参数的定量文献验证未通过，不能用于该样品的定量器件设计；运行结果见 [自动报告](literature-results.md)。

已加入有条件界面档案、带隙类别、网格比较及有边界条件的 1D 体硅平衡求解。后续异质界面、接触、复合、光生或缺陷动态模型仍需独立校准集与留出验证集，并报告参数相关性和误差；不能通过给通用 Shockley 曲线调参数来代替这些器件机制。
